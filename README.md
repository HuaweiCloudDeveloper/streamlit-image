## Project Introduction

[Streamlit](https://github.com/streamlit/streamlit) is an open-source Python library for creating data applications and interfaces for machine learning models. It allows developers to quickly build interactive web applications without in-depth knowledge of front-end development technologies. The product deployment is based on the arm architecture of the Huawei Cloud EulerOS 2.0 64-bit system.

**Why Choose Streamlit?**

**‌Simple and Pythonic:** Write concise and readable code.

**‌Rapid, Interactive Prototyping:** Enable others to quickly interact with your data and get feedback.

**‌Real-time Editing:** Instantly view application updates while editing scripts.

**‌Open Source and Free:** Join an active community to shape the future of Streamlit together.

The open-source image product [**Streamlit Data Science Application Tool**](https://marketplace.huaweicloud.com/contents/859b57e8-a9dd-431f-a724-da999b0553ea#productid=OFFI1121279984920113152) provided by this project has the Streamlit version 1.40.1 and its related runtime environment pre-installed, and also provides a deployment template. Refer to the usage guide and start your efficient "out-of-the-box" experience now!

> **System requirements are as follows:**
> - CPU: 2vCPUs or higher
> - RAM: 4GB or more
> - Disk: At least 40GB
